# StyleSync 개인정보 처리 방침 (서비스 내부 정책)

> 이 문서는 StyleSync 서비스의 개인정보 처리 원칙을 정의합니다.
> 운영 정책 변경 시 이 문서를 함께 갱신합니다.

---

## 1. 수집하는 정보

| 정보 유형 | 수집 여부 | 비고 |
|-----------|-----------|------|
| 이메일 | ✅ 수집 | Google OAuth 로그인 시, 서비스 제공 목적 |
| 취향 입력 (음악·영화·패션 선택) | ✅ 수집 | AI 추론 결과 생성 목적, 본인만 접근 |
| AI 추론 결과 (스타일 레이블, 추천 목록) | ✅ 수집 (저장 시) | 로그인 사용자의 명시적 저장 선택 시 |
| 전화번호 | ❌ 미수집 | 수집하지 않음 |
| 주민등록번호 | ❌ 미수집 | 수집하지 않음 |
| 결제 정보 | ❌ 미수집 | 결제·구매 기능 없음 |

## 2. 정보 이용 목적

- 취향 데이터는 **AI 추론 결과 생성** 목적으로만 사용됩니다.
- 취향 데이터를 **외부에 판매하거나 제3자와 공유하지 않습니다.**
- AI 추론 시 Grok API에 취향 선택 정보가 전달되나, 세션 단위로만 사용됩니다.

## 3. 자동 결제·구매

- StyleSync는 **자동 콘텐츠 구매·결제 기능을 제공하지 않습니다.**
- 서비스 내 모든 추천은 외부 서비스(Spotify, TMDB, Unsplash) 링크 표시에 그치며, 실제 결제는 해당 외부 서비스에서 이루어집니다.

## 4. API 키 보안

아래 서비스 키는 서버 전용으로만 사용하며, 클라이언트 번들에 포함되지 않습니다.

| API 키 | 사용처 | 서버 전용 |
|--------|--------|----------|
| `GROK_API_KEY` | AI 추론 | ✅ |
| `SPOTIFY_CLIENT_ID/SECRET` | 아티스트 검색 | ✅ |
| `TMDB_API_KEY` | 영화 검색 | ✅ |
| `UNSPLASH_ACCESS_KEY` | 패션 이미지 | ✅ |
| `SUPABASE_SERVICE_ROLE_KEY` | DB 서버 관리 | ✅ |

`NEXT_PUBLIC_SUPABASE_URL` 및 `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY`는 Supabase의 공개 클라이언트 키로, 클라이언트 노출이 의도된 값입니다.

## 5. 데이터 접근 제어

- 저장된 추론 결과는 Supabase Row-Level Security (RLS) 정책에 의해 **본인만 접근** 가능합니다.
- 비로그인 사용자의 결과는 `sessionStorage`에만 임시 저장되며, 탭 종료 시 삭제됩니다.
